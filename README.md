# 中国地名搜索 · QGIS 插件

> 在 QGIS 定位器（<kbd>Ctrl</kbd>+<kbd>K</kbd>）里输入中国地名，回车即飞到位。
> 双数据源 · 同音字容错 · 拼音搜索 · 结果落点。
>
> A QGIS locator plugin for searching Chinese place names — two data
> sources, homophone-tolerant and pinyin-aware.

---

## 它解决什么问题

在 QGIS 里找一个地名，传统做法是：切到浏览器 → 打开地图网站 → 搜 → 记下坐标 → 切回 QGIS → 定位。
这个插件把这一串压缩成一次按键：**Ctrl+K，打地名，回车**。

三个实际痛点：

- **打错字就搜不到** —— 「匡河镇」打成「框河镇」，多数接口直接给你 0 条。本插件会自动按同音字重试。
- **只会读不会写** —— 可以只输拼音 `kuanghezhen`。
- **想找的是"那一带有什么"** —— 天地图源按**当前地图视野**搜索，你看哪块就搜哪块。

---

## 功能

| 能力 | 说明 |
|---|---|
| 双数据源 | 民政部国家地名信息库（标准地名 + 历史沿革）、天地图 POI（全量兴趣点） |
| 同音字容错 | 「框河镇」→ 自动尝试「匡河镇」，逐位轮转，词首词尾的错字都能覆盖 |
| 拼音搜索 | 直接输 `kuanghezhen`、`sanlifan`，自动切分音节并转汉字候选 |
| 视野内搜索 | 天地图源使用当前地图范围，级别由比例尺自动换算 |
| 结果落点 | 命中后地图飞到该位置，并在「地名搜索结果」图层落点，多次搜索累积 |
| 请求可控 | 平时 1 次请求；容错时最多再试 6 次 |

## 安装

### 方式一：从 ZIP 安装（推荐）

1. 下载本仓库，把内容打包成 zip（**注意：`metadata.txt` 必须在 zip 根目录**）
2. QGIS → 插件 → 管理并安装插件 → **从 ZIP 安装**
3. 勾选启用

### 方式二：手动拷贝

把整个目录复制到 QGIS 插件目录并改名为 `qgis_cn_place_search`：

| 系统 | 路径 |
|---|---|
| Windows | `%APPDATA%\QGIS\QGIS3\profiles\default\python\plugins\` |
| Linux | `~/.local/share/QGIS/QGIS3/profiles/default/python/plugins/` |
| macOS | `~/Library/Application Support/QGIS/QGIS3/profiles/default/python/plugins/` |

> QGIS 4.x 把 `QGIS3` 换成 `QGIS4`。目录名必须是 `qgis_cn_place_search`（下划线，不能带横线）。

## 使用

按 <kbd>Ctrl</kbd>+<kbd>K</kbd> 打开定位器：

```
匡河镇              → 查民政部地名库（标准地名，带来历与沿革）
dm 匡河镇           → 同上，强制走民政部
tdt 医院            → 查天地图 POI，在【当前地图视野】内搜索
框河镇              → 打错了也没关系，自动按同音字重试
kuanghezhen        → 直接输拼音
```

> `tdt` 后面**要有空格**。`tdt医院` 连写不会被识别为前缀。

选中结果回车后：地图飞过去 + 在「地名搜索结果」图层落一个点。

## 配置天地图 Key

**天地图数据源需要 Key**（民政部源不需要）。Key 不写死在代码里，读取顺序：

1. QGIS 设置项 `qgis_cn_place_search/tianditu_tk`
2. 环境变量 `TIANDITU_TK`

**推荐做法**：插件菜单 → **中国地名搜索 → 设置天地图 Key…**，填完即生效，无需重启。

Key 申请：<https://console.tianditu.gov.cn/>（免费，需实名）

> 未配置 Key 时，天地图源会返回一条提示结果，民政部源照常工作。

## 数据来源与合规

| 数据源 | 提供方 | 说明 |
|---|---|---|
| 国家地名信息库 | 民政部区划地名司 | <https://dmfw.mca.gov.cn> |
| 天地图 Web 服务 API | 国家基础地理信息中心 | <https://api.tianditu.gov.cn> |

- 两者均为**随查随取**的公开查询接口，本插件**不缓存、不批量抓取、不落库**。
- 每次搜索的请求次数与关键词一一对应（容错时最多 7 次），不存在后台扫描。
- 地名来历 / 历史沿革等文字内容的著作权归民政部区划地名司，本插件仅作查询展示。
- 请遵守各数据源的服务条款；天地图 Key 的配额与合规使用由使用者自行负责。

## 已知限制

- **天地图源在级别低于 10 时不返回结果** —— 接口行为，插件已把级别夹到 10–18。
- **视野特别大时，天地图返回的结果可能不在地图范围内** —— 它的 `mapBound` 是偏好而非硬过滤。建议放大到城市级别再搜。
- **同音容错不是万能的** —— 只替换同音字，不纠正形近字或不同音的字。默认最多试 6 个候选，词尾的生僻错字可能仍找不到。
- **拼音转汉字依赖字频排序** —— 极少用字组合可能排在候选之外。
- 两个数据源的字段与覆盖范围不同，同一地名可能只有一个源能搜到。

## 开发

### 目录结构

```
qgis-cn-place-search/
├── metadata.txt              插件元数据（QGIS 读取）
├── __init__.py               classFactory 入口
├── plugin.py                 插件主体：注册滤镜 + 设置入口
├── locator.py                两个定位器滤镜 + 定位落点逻辑
├── sources.py                民政部 / 天地图 两个数据源的 API 封装
├── pinyin.py                 拼音表加载、同音候选、拼音切分
├── pinyin_table.json         拼音表（生成物，已随仓库提供）
├── tools/
│   └── build_pinyin_table.py 生成拼音表（需要 pypinyin）
├── LICENSE
└── README.md
```

### 重新生成拼音表

拼音表的质量直接决定同音容错的命中速度。它由地名语料统计而来：

```bash
pip install pypinyin
python tools/build_pinyin_table.py 地名语料.geojson [更多语料 ...]
```

生成脚本做三件事：

1. **统计语料字频** —— 地名里常见的字排在各自音节前面
2. **给通名加高权重** —— 保证「县 / 市 / 区 / 镇 / 乡 / 村」稳居首位，否则纯靠语料统计会得到「罗田仙」而不是「罗田县」
3. **按 GB2312 字库分层** —— 常用字优先于生僻字，避免「儣」压过「匡」

不给语料时退化为「全汉字区」，能用但命中率下降。
